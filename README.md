# RGB LED Blinking with Arduino UNO

A simple Arduino project demonstrating how to control and blink an RGB LED using an Arduino UNO.

This is my second Arduino project and one of my small steps toward learning embedded systems and electronics.

## Components

* Arduino UNO
* RGB LED
* Breadboard
* Jumper wires
* Resistors
* USB cable

## How It Works

The RGB LED is connected to the Arduino through the breadboard. The Arduino controls the RGB channels using digital output pins, allowing different colors to be produced through the code.

## Learning Outcomes

Through this project, I practiced:

* Arduino digital output
* RGB LED control
* Basic circuit wiring
* Resistor usage
* Breadboard prototyping
* Arduino programming

A small project, but another step toward building practical embedded systems and electronics skills. 🚀
